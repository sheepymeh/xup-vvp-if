$ bwconfig --help
Usage:
bwconfig [actions] [options]
Command help and version information:
--help[=<scan|add|remove|get|set|load|erase|reset|start|peek|poke>]
--version
View, scan for, add and remove devices:
--list
--scan=<network|pci|usb> [options]
--add=<network|pci|usb> [options]
--remove=N
Get, set resource properties:
--get=<device|resource|system>
--set=<device|resource|system>
Reset, load, start, erase resources:
--load=filename[,flags] (default flags=0x203=load,compressed)
--erase
--reset[=flags]
--start
Read, write resources:
--peek=A
--poke=A
Save, restore PCIe device:
--save=N
--restore=N

$ bwconfig --help=scan
bwconfig (cli) help: scan
--scan=pci [--vendor=VID] [--dev-id=DID]
Use '0x' prefix before VID or DID values.
--scan=network --ip=IP[-LAST] [--port=PORT]
--scan=usb [--vendor=VID] [--dev-id=DID]
Examples:
Scan for all BittWare PCI devices,
bwconfig --scan=pci
Scan for all PCI devices,
bwconfig --scan=pci --vendor=0
Scan for BittWare FPGA PCIe devices (see hil.h),
bwconfig --scan=pci --dev-id=0x41
Scan for BittWare network devices on IPs 10.20.0.5 to 10.20.0.245
bwconfig --scan=network --ip=10.20.0.5-245
Scan for BittWare network devices at a certain address and port
bwconfig --scan=network --ip=192.168.1.5 --port=4794
Scan for all BittWare USB devices,
bwconfig --scan=usb

$ bwconfig --help=add
bwconfig (cli) help: add
--add=pci [--vendor=VID] [--dev-id=DID] [--result=N]
Use '0x' prefix before VID or DID values.
--add=network --ip=IP[-LAST] [--port=PORT] [--result=N]
--add=usb [--vendor=VID] [--dev-id=DID] [--result=N]
Examples:
Add the first BittWare PCI devices,
bwconfig --add=pci
Add the second BittWare FPGA PCIe device,
bwconfig --add=pci --dev-id=0x41 --result=1
Add the first BittWare network device on IP 10.20.0.5 to 10.20.0.245
bwconfig --add=network --ip=10.20.0.5-245
Add device 3 on server at 192.168.1.5
bwconfig --scan=network --ip=192.168.1.5 --result=3
Add the first BittWare USB device found,
bwconfig --scan=usb

$ bwconfig --help=get
bwconfig (cli) help: get
--get=system [--prop=PROP]
--get=device [--dev=N] [--prop=PROP]
--get=resource [--dev=N] --type=<fpga|flash|bar>
[--index=I] [--prop=PROP]
Examples:
Get all of the system properties
bwconfig --get=system
Get the name of your bwserver
bwconfig --get=system --prop=HIL_SERVER_NAME_STR
Get all of the device properties for device 0
bwconfig --get=device
Get the serial number of device 1
bwconfig --dev=1 --get=device --prop=HIL_SERIAL_NUMBER_STR
Get all of the properties for the second FPGA resource on device 0
bwconfig --get=resource --type=fpga --index=1
Get the name of the first FPGA on device 0.
bwconfig --get=resource --type=fpga --prop=HIL_FPGA_NAME_STR

--prop=HIL_FPGA_NAME_STR --newvalue='fpga0'

$ bwconfig --help=peek
bwconfig (cli) help: peek
--peek=OFFSET [--dev=N] --type=<fpga|flash|bar> [--index=I] [--count=C]
[--width=W]
Reads C words of W sized data (4 bytes by default) starting at
offset OFFSET.
Examples:
Read 2 32-bit words from offset 0 of the first FPGA
bwconfig --peek=0 --type=fpga --count=2
Read 8 bytes from offset 0x200 of BAR2
bwconfig --peek=0x200 --type=bar --index=2 --width=1 --count=8

$ bwconfig --help=poke
bwconfig (cli) help: poke
--poke=OFFSET [--dev=N] --type=<fpga|flash|bar> [--index=I] [--count=C]
[--width=W] --newvalue=VALUE
Writes VALUE C times using W sized data (4 bytes by default) starting at
offset OFFSET.
Examples:
Write 2 zeroes as 32-bit words to offset 0 of the first FPGA
bwconfig --poke=0 --type=fpga --count=2 --newvalue=0
Write 0x12 as a byte to offset 0x200 of BAR2
bwconfig --poke=0x200 --type=bar --index=2 --width=1
