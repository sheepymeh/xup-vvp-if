$ bwmonitor --help
Usage: bwmonitor <options>
Where <options> are:
--device=<DEVICE>[,DEVICE[,...]] : connect using HIL device entry number(s).
--port=<COMPORT>                 : connect over serial port.
--baud=<BAUD>                    : serial port rate. Defaults to 9600.
--type=<TYPE>                    : one of FMC, Sensor, SFP, DIMM, BMC, Clock, Fpga,
Power, Network. Defaults to listing/reading all.
--file=<FILENAME>                : src/dest file for reading/writing. Defaults to
STDIN/STDOUT.
--dev=<DEVICE>[,DEVICE[,...]]    : alias for --device=
--uart0=<VALUE>                  : first UART mux register value
--uart1=<VALUE>                  : second UART mux register value
--flags[=<VALUE>]                : BMC Flags value for --type=BMC
--flags1[=<VALUE>]               : BMC Flags1 value for --type=BMC
--i2c_own[=<VALUE>]              : I2C ownership override value for --read or --write
--type=BMC and --value where 1 indicates
BMC ownership.
--last_error                     : BMC last error for --read --type=BMC
--logfile=<PATH>                 : Path to log file.
--logfileflags=<append>          : Add mode to append. Default mode is overwrite.
--logformat=<simplified>         : Use simplified output. Default format is plain.
--verbose                        : be more verbose. Shows sensor thresholds when
reading sensors.
Operations: where <ID> is the FRU index, SDR index, or id.
--help[=examples]                : Show help or examples
--list                           : list components of type <TYPE>
--read[=<ID>]                    : read component <ID> of type <TYPE>
--write[=<ID>]                   : write to component <ID> of type <TYPE>.
<FILENAME> used for FRU read/write*,
microcontroller upgrade, clock program.
--i2cread                        : read I2c device
--devaddr=<DEV>                    I2C device address
--addr=<ADDR>                      8-bit PROM address
--count=<COUNT>                    number of bytes to read
--i2cwrite                       : write to an I2c device
--devaddr=<DEV>                    I2C device address
--addr=<ADDR>                      8-bit PROM address
--strval=<STRVAL>                  Use strval to write a string. Use \n as separator
--hexval=<HEXVAL,...,HEXVAL>       Use hexval to write hex values
--loop[=<N>]                     : loop read operation until N seconds have passed.
Defaults to forever.
--read_every=<F>                   used with loop; perform read operation every F seconds
--power=<P>                      : 0 to remove board power or 1 to apply power
--shell                          : open raw IPMI command shell
--clear-cache                    : clear SDR and peripheral table caches.
--version                        : report program and firmware versions.

$ bwmonitor --help=examples
Examples:
Read all sensors on device 0
bwmonitor --read --type=Sensor

Read all sensors on devices 0-3
bwmonitor,1,2,3 --read --type=Sensor

Read all sensors in a loop for 60 seconds, reading every 5 seconds
bwmonitor --read --type=Sensor --loop=60 --read_every=5

Read all sensors in a loop for 60 seconds, reading every 5 seconds and log the output
bwmonitor --read --type=Sensor --loop=60 --read_every=5 --logfile=bwmon.log --logformat=simplified --logfileflags=append

Write programming file to clock 0
bwmonitor --write=0 --type=Clock --file=/path/to/si5338a.h

Upgrade microcontroller firmware
bwmonitor --write=1 --type=BMC --file=/path/to/hpm1fw.img

Read 32 bytes from I2C channel 4, device 0xA0 starting at address 0
bwmonitor --dev=0 --i2cread --devaddr=0x4a0 --addr=0 --count=32

Write '<tab>test<newline>' to a PROM on I2C channel 4, device 0xA0 starting at address 0
bwmonitor --dev=0 --i2cwrite --devaddr=0x4a0 --addr=0 --strval=\ttest\n

Open raw IPMI command terminal to device 0
bwmonitor --dev=0 --shell
